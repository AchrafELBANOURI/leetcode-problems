# LeetCode Daily Challenges 🧠📅

Welcome to my personal repository where I solve and document daily coding problems from [LeetCode](https://leetcode.com/). This is part of my continuous effort to improve algorithmic thinking, master data structures, and prepare for technical interviews.

---

## 📌 Repository Structure

Each folder is named by date (`YYYY-MM-DD`) or by problem title, and contains:
- ✅ The problem statement (link)
- 🧠 My solution(s)
- 💬 Explanation or reasoning (in comments or a separate markdown file)

---

## 🚀 Goals

- Solve at least **one problem daily**
- Cover a wide range of topics: arrays, strings, trees, graphs, DP, etc.
- Write clean, optimized, and well-documented code
- Revisit and refactor older solutions
